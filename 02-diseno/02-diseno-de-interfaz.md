# Diseño de Interfaz – Guayaba Clara

## Principios de diseño
- Estética limpia y profesional, alineada con un producto de café de origen colombiano.
- Uso de tipografía clara, contraste adecuado y espacios generosos.
- Responsive (móvil primero o adaptable).
- Feedback visual inmediato (estados de carga, mensajes de éxito/error).

## Páginas principales

### 1. Página de inicio (`index.html`)
- Header con navegación y acceso a cuenta.
- Sección de acceso / cuenta (registro e inicio de sesión embebidos).
- Hero: mensaje de valor del café colombiano.
- Métricas rápidas (hectáreas, clientes, etc.).
- Catálogo de productos.
- Carrito lateral o modal.
- Sección de origen / historia.
- Chat o contacto con “Clara”.

### 2. Login / Registro
- Formularios simples y claros.
- Validación en cliente y servidor.
- Mensajes de error amigables.

### 3. Panel de Administración (`admin.html`)
- Acceso restringido por rol.
- Dashboard con métricas.
- Gestión de productos (tabla + formularios).
- Listado de pedidos con cambio de estado.
- Gestión de promociones WhatsApp.
- Botón de cierre de sesión.

## Componentes de UI
- Botones primarios y secundarios.
- Cards de producto.
- Formularios con feedback de estado.
- Listas de pedidos.
- Indicadores de stock bajo.

## Colores y tipografía (referencia)
- Tonos tierra / café / crema para transmitir origen y calidad.
- Tipografía sans-serif moderna y legible.
- Uso de énfasis tipográfico (*cursivas* o em) para títulos de impacto.
